# Textured Surfaces — Re-Run Against Current Main

## Goal

Re-implement the [`textured-surfaces`](../textured-surfaces.md) spec against
the current `index.html`. The first attempt (PR #17) was a clean implementation
but branched from `589fed1` (just after the spec was authored), and `main` has
since received `atmosphere-lighting` (#16) and `gun-viewmodel` (#18) — both of
which rewrote large parts of `render()`. The merge conflicts were dense enough
to be cheaper to redo than to resolve.

The original spec already anticipates this in its AC #14: "sample the texture
*first* … and then run the existing fog/vignette pass on the textured pixel".
This task pins down exactly how that composition lands now that atmosphere and
the gun viewmodel are real, in-tree code rather than future specs.

The visual contract from the original spec is unchanged: walls, floor, and
ceiling get procedurally-baked 64×64 textures; brick reads as brick, stone
reads as stone, floor/ceiling are clearly textured, and the player can tell
them apart at any in-game distance. The L key still toggles atmosphere
(fog + sky/ground gradient + vignette) on top of the textured world.

## Acceptance Criteria

1. **Original spec contract holds.** Every acceptance criterion in
   `specs/textured-surfaces.md` (#1–#15) applies as written, *except* #14
   which is superseded by AC #6–#8 below (now that the composition target is
   concrete in-tree code, not a future spec). Visual identity per texture
   (brick / stone / floor / ceiling), the deterministic LCG, the mirror rule
   for `texX`, the `WALL_TEX` lookup, the side-darken, and ≥ 30 FPS at
   480×270 are all binding.

2. **Single-file constraint preserved.** Still one `index.html` at the repo
   root, no `package.json`, no external assets, no build step, no
   `localStorage`, no network requests. All texture pixels are generated by
   JS at startup. **`Math.random()` is forbidden** in the texture
   generators — use the seeded LCG so the first rendered frame is
   byte-identical across page reloads.

3. **`castColumn` return shape extends, doesn't break.** Add `rayDirX` and
   `rayDirY` to the returned object:
   ```js
   return { perpWallDist, side, wallType, rayDirX, rayDirY };
   ```
   No other call site of `castColumn` (e.g. `castRay`, `enemyCanSeePlayer`,
   `drawMinimap`) reads the new fields, so adding them is a no-op for
   everyone except the textured wall path. Do not duplicate the camera math
   in `render()` — read `hit.rayDirX` / `hit.rayDirY` instead.

4. **Texture registry exists exactly once.**
   ```js
   const TEX_SIZE = 64;
   const TEX_MASK = TEX_SIZE - 1;
   const TEXTURES = {
     brick:   genBrick(),
     stone:   genStone(),
     floor:   genFloor(),
     ceiling: genCeiling(),
   };
   const WALL_TEX = { 1: TEXTURES.brick, 2: TEXTURES.stone };
   ```
   Place this block after the `rgba32` / `HALF_H` declarations and **before**
   the atmosphere-lighting block (`FOG_C`, `SKY_ROW`, `GROUND_ROW`,
   `VIGNETTE`) so the atmosphere block can be edited or pruned in step with
   the new floor/ceiling pass without re-ordering. The four generators may
   be lifted from PR #17's diff — they meet the visual-identity bar — or
   re-derived from scratch as long as #4 of the original spec is met.

5. **Textures apply in BOTH lighting modes.** The L toggle continues to gate
   only the atmosphere effects (fog blend, sky/ground gradients, vignette).
   Walls, floor, and ceiling are textured regardless of `lightingEnabled`.
   When the toggle is off, the world is "textured + 1/d distance shade,
   no fog, no gradient, no vignette" — i.e. the legacy debug path the toggle
   was designed for, just with textures swapped in for flat colors.

6. **Wall composition order — lighting ON.** For each wall column:
   1. Sample the texture pixel at `(texX, texY)` from
      `WALL_TEX[hit.wallType]`. Use the fixed-point texY step
      (`step = (TEX_SIZE << 16) / lineHeight | 0`) and the standard mirror
      rule for `texX`.
   2. Apply side darkening: multiply each channel by 0.6 when `hit.side === 1`.
   3. Apply fog: blend the (textured, side-shaded) channels toward `FOG_C`
      using the existing wall-fog formula
      (`t = clamp((d - FOG_NEAR) / (FOG_FAR - FOG_NEAR), 0, 1)`,
      `rgb = rgb * (1-t) + fogRgb * t`). The fog formula must be the
      *same* one currently in `render()` at lines ~1400-1414 — do not
      reinvent it.
   4. Write the result to `buf32`. The vignette pass at the end of
      `render()` then runs over the whole buffer and darkens screen
      corners — unchanged.

7. **Wall composition order — lighting OFF.** Same as #6 but step 3 is
   replaced with the legacy distance shade
   (`shade = Math.min(1, 5 / (d + 0.5))`, `rgb = rgb * shade`), and no
   vignette pass runs. Side-darken still applies.

8. **Floor and ceiling per-row cast replaces BOTH background paths.**
   Today, `render()` chooses between (a) the per-row `SKY_ROW` /
   `GROUND_ROW` gradient fills (lighting on) and (b) `fillBackground()`
   (lighting off) before the wall column loop. After this task, both are
   gone — replaced by a single `castFloorCeiling()` pass that runs every
   frame and samples `TEXTURES.floor` / `TEXTURES.ceiling` per pixel for
   `y` in `[HALF_H+1, H)`, mirroring to the ceiling row at `H - 1 - y`.
   Per-row math:
   ```
   p       = y - HALF_H
   rowDist = HALF_H / p
   stepX   = rowDist * (rayDirX1 - rayDirX0) / W
   stepY   = rowDist * (rayDirY1 - rayDirY0) / W
   fx      = player.x + rowDist * rayDirX0
   fy      = player.y + rowDist * rayDirY0
   ```
   Inner loop steps `(fx, fy)` by `(stepX, stepY)` per screen-x and samples
   each texture at `((fx*TEX_SIZE)|0) & TEX_MASK`,
   `((fy*TEX_SIZE)|0) & TEX_MASK`. The horizon row (`p === 0`) is filled
   with a single `buf32.fill(0xff000000, ...)` (or skipped, since walls
   typically overdraw it).

9. **Floor/ceiling shading — lighting ON.** Per row, use `rowDist` to fog
   each pixel toward `FOG_C` using the same formula as the wall path
   (AC #6 step 3). The fog `t` is computed once per row from `rowDist` and
   reused as a fixed-point integer multiplier (`it = (t * 256) | 0`,
   `ib = 256 - it`). The vignette pass at the end of `render()` then runs
   over floor/ceiling pixels too. The visual outcome should be: near floor
   tiles read as the textured warm-grey stone; far floor tiles fade
   smoothly into the same `FOG_C` horizon the walls fade into; sky/ground
   gradients (`SKY_ROW`, `GROUND_ROW`) are no longer drawn — the textured
   floor/ceiling carry the atmosphere instead.

10. **Floor/ceiling shading — lighting OFF.** Per row, apply the legacy
    `shade = Math.min(1, 5 / (rowDist + 0.5))` distance shade as a
    fixed-point integer (`shadeI = (shade * 256) | 0`). No fog, no
    vignette. Far rows go to near-black naturally. This matches the spec's
    AC #9 ("Distance shade preserved … now also to floor/ceiling using
    each row's `rowDist`").

11. **Inner-loop hygiene.** The wall column inner loop and the
    `castFloorCeiling` inner loop must be branch-free per pixel — extract
    the lighting-mode decision *outside* the loop. The cleanest form is
    two specialized inner-loop variants per pass selected at the top of
    the function:
    ```js
    if (lightingEnabled) { /* fogged inner loop */ }
    else                 { /* shaded inner loop */ }
    ```
    Per-pixel reads/writes stay in `Uint32Array`; channel extract /
    multiply / repack is integer-only (no float intermediates per pixel).

12. **`SKY_ROW` and `GROUND_ROW` removal.** The two `Uint32Array(HALF_H)` /
    `Uint32Array(H - HALF_H)` precomputed gradient buffers and their
    initialization block (currently lines ~491-513 of `index.html`) become
    dead code once the per-row cast handles the background, and must be
    deleted in this task. Their initialization was the visual contract for
    the *old* atmosphere implementation; the new contract is "fog blends
    textured floor/ceiling toward `FOG_C`", which produces the same
    horizon read without the gradient. Removing them keeps the renderer
    block honest.

13. **`fillBackground()` removal.** The flat-fill helper (currently lines
    ~1355-1358) is no longer called and must be deleted alongside its
    `CEIL_C` / `FLOOR_C` constants (lines ~470-471). If you find yourself
    keeping `CEIL_C` / `FLOOR_C` "as a fallback", stop — there is no
    fallback path; both modes go through the per-row cast.

14. **Sprite renderer untouched.** `drawSprites()` (lines ~1787-1933) and
    `drawEnemyMuzzleFlashes()` already handle their own fog blend (the
    `lightingEnabled` branch at ~1846 and the muzzle-flash overlay path).
    They sit between the wall column loop and the vignette pass and are
    not affected by this change. Z-buffer occlusion (`zBuffer[stripe]`)
    continues to work because the wall pass still writes to `zBuffer[x]`.

15. **Gun viewmodel untouched.** `drawGunViewmodel()` runs *after* the
    vignette pass (line ~1445) so the gun reads as HUD-class and is not
    darkened at the corners. This task does not touch that ordering. The
    only thing that changes for the gun is that the world behind it is
    now textured.

16. **Vignette pass unchanged.** The `lightingEnabled` per-pixel
    `VIGNETTE` multiply pass (lines ~1427-1440) still runs over the
    final `buf32` after walls + sprites. It naturally darkens textured
    floor/ceiling/walls at the corners — which is the desired visual.
    Do not move, gate, or duplicate it.

17. **Determinism.** A page reload produces a byte-identical first frame.
    Verify by re-loading the page twice, snapping the same first-frame
    canvas pixel data via DevTools, and diffing — they must match. The
    LCG seeds in the four generators are part of the spec contract; do
    not seed them with `Date.now()`, `Math.random()`, or any other
    nondeterministic source.

18. **No new console errors or warnings.** A 60-second session covering
    walking through every reachable cell, toggling L, dying and pressing
    R, and pressing N to regenerate — all clean.

19. **Performance.** ≥ 30 FPS at 480×270 with the procedurally-generated
    map and all initial enemies alive, in both lighting modes. The
    floor/ceiling per-row cast adds ~64,800 pixel ops per frame; keep
    the inner loop integer-only and let V8 inline it. The fog/shade
    multiplier should be a single fixed-point integer per row (computed
    outside the x loop), so per-pixel cost is just three channel
    extracts, three multiplies, and a repack.

20. **The L overlay text continues to read `lighting: on` / `lighting: off`.**
    No new debug text, no "textures: on" overlay. Texturing is a permanent
    visual upgrade, not a togglable feature.

- **Mirror rule for `texX`** (per the standard Lode-Vandevenne
  formulation): mirror when `(side === 0 && rayDirX > 0)` OR
  `(side === 1 && rayDirY < 0)` so adjacent walls' textures meet at
  corners without flipping. This is the same rule the original spec
  calls out and PR #17 implemented correctly.

- **Floor/ceiling cast sketch** (per-frame, runs once at the top of
  `render()`):
  ```js
  function castFloorCeiling() {
    const FLOOR_TEX = TEXTURES.floor;
    const CEIL_TEX  = TEXTURES.ceiling;
    const rayDirX0 = player.dirX - player.planeX;
    const rayDirY0 = player.dirY - player.planeY;
    const rayDirX1 = player.dirX + player.planeX;
    const rayDirY1 = player.dirY + player.planeY;
    const dRayX = (rayDirX1 - rayDirX0) / W;
    const dRayY = (rayDirY1 - rayDirY0) / W;
    // Hoist fog channel constants when lit.
    const fogR = FOG_C & 0xff;
    const fogG = (FOG_C >> 8) & 0xff;
    const fogB = (FOG_C >> 16) & 0xff;
    const fogDenom = FOG_FAR - FOG_NEAR;

    for (let y = HALF_H + 1; y < H; y++) {
      const p = y - HALF_H;
      const rowDist = HALF_H / p;
      const stepX = rowDist * dRayX;
      const stepY = rowDist * dRayY;
      let fx = player.x + rowDist * rayDirX0;
      let fy = player.y + rowDist * rayDirY0;
      let iFloor = y * W;
      let iCeil  = (H - 1 - y) * W;

      if (lightingEnabled) {
        let t = (rowDist - FOG_NEAR) / fogDenom;
        if (t < 0) t = 0; else if (t > 1) t = 1;
        const it = (t * 256) | 0;
        const ib = 256 - it;
        for (let xx = 0; xx < W; xx++) {
          const tx = ((fx * TEX_SIZE) | 0) & TEX_MASK;
          const ty = ((fy * TEX_SIZE) | 0) & TEX_MASK;
          const idx = ty * TEX_SIZE + tx;
          const cF = FLOOR_TEX[idx];
          const cC = CEIL_TEX[idx];
          const fr = ((((cF      ) & 0xff) * ib + fogR * it) >> 8);
          const fg = ((((cF >>  8) & 0xff) * ib + fogG * it) >> 8);
          const fb = ((((cF >> 16) & 0xff) * ib + fogB * it) >> 8);
          buf32[iFloor++] = (255 << 24) | (fb << 16) | (fg << 8) | fr;
          const cr = ((((cC      ) & 0xff) * ib + fogR * it) >> 8);
          const cg = ((((cC >>  8) & 0xff) * ib + fogG * it) >> 8);
          const cb = ((((cC >> 16) & 0xff) * ib + fogB * it) >> 8);
          buf32[iCeil++] = (255 << 24) | (cb << 16) | (cg << 8) | cr;
          fx += stepX;
          fy += stepY;
        }
      } else {
        const shade = Math.min(1, 5 / (rowDist + 0.5));
        const shadeI = (shade * 256) | 0;
        for (let xx = 0; xx < W; xx++) {
          const tx = ((fx * TEX_SIZE) | 0) & TEX_MASK;
          const ty = ((fy * TEX_SIZE) | 0) & TEX_MASK;
          const idx = ty * TEX_SIZE + tx;
          const cF = FLOOR_TEX[idx];
          const cC = CEIL_TEX[idx];
          const fr = (((cF      ) & 0xff) * shadeI) >>> 8;
          const fg = (((cF >>  8) & 0xff) * shadeI) >>> 8;
          const fb = (((cF >> 16) & 0xff) * shadeI) >>> 8;
          buf32[iFloor++] = (255 << 24) | (fb << 16) | (fg << 8) | fr;
          const cr = (((cC      ) & 0xff) * shadeI) >>> 8;
          const cg = (((cC >>  8) & 0xff) * shadeI) >>> 8;
          const cb = (((cC >> 16) & 0xff) * shadeI) >>> 8;
          buf32[iCeil++] = (255 << 24) | (cb << 16) | (cg << 8) | cr;
          fx += stepX;
          fy += stepY;
        }
      }
    }
    // Horizon row — single black fill (walls usually overdraw it).
    buf32.fill(0xff000000, HALF_H * W, HALF_H * W + W);
  }
  ```

- **Wall column sketch** (replaces the existing column body inside
  `render()`'s `for (let x = 0; x < W; x++)` loop):
  ```js
  const hit = castColumn(x);
  const d = hit.perpWallDist;
  zBuffer[x] = d;

  const tex = WALL_TEX[hit.wallType] || TEXTURES.brick;
  const rayDirX = hit.rayDirX;
  const rayDirY = hit.rayDirY;

  let wallX = (hit.side === 0)
    ? (player.y + d * rayDirY)
    : (player.x + d * rayDirX);
  wallX -= Math.floor(wallX);
  let texX = (wallX * TEX_SIZE) | 0;
  if ((hit.side === 0 && rayDirX > 0) || (hit.side === 1 && rayDirY < 0)) {
    texX = TEX_MASK - texX;
  }

  let lineHeight = (H / d) | 0;
  if (lineHeight < 1) lineHeight = 1;
  const drawStart = (H - lineHeight) >> 1;
  const drawEnd   = drawStart + lineHeight;
  const yStart = drawStart < 0 ? 0 : drawStart;
  const yEnd   = drawEnd > H ? H : drawEnd;
  const step   = ((TEX_SIZE << 16) / lineHeight) | 0;
  let texPos   = ((yStart - drawStart) * step) | 0;

  const sideMul = (hit.side === 1) ? 0.6 : 1.0;

  if (lightingEnabled) {
    let t = (d - FOG_NEAR) / fogDenom;
    if (t < 0) t = 0; else if (t > 1) t = 1;
    const it = (t * 256) | 0;
    const ib = 256 - it;
    const sideI = (sideMul * 256) | 0;
    let i = yStart * W + x;
    for (let y = yStart; y < yEnd; y++) {
      const tY = (texPos >>> 16) & TEX_MASK;
      texPos = (texPos + step) | 0;
      const c = tex[tY * TEX_SIZE + texX];
      const r0 = ((c & 0xff) * sideI) >>> 8;
      const g0 = (((c >>>  8) & 0xff) * sideI) >>> 8;
      const b0 = (((c >>> 16) & 0xff) * sideI) >>> 8;
      const r = (r0 * ib + fogR * it) >> 8;
      const g = (g0 * ib + fogG * it) >> 8;
      const b = (b0 * ib + fogB * it) >> 8;
      buf32[i] = (255 << 24) | (b << 16) | (g << 8) | r;
      i += W;
    }
  } else {
    const shade = Math.min(1, 5 / (d + 0.5));
    const shadeI = (shade * sideMul * 256) | 0;
    let i = yStart * W + x;
    for (let y = yStart; y < yEnd; y++) {
      const tY = (texPos >>> 16) & TEX_MASK;
      texPos = (texPos + step) | 0;
      const c = tex[tY * TEX_SIZE + texX];
      const r = ((c & 0xff) * shadeI) >>> 8;
      const g = (((c >>>  8) & 0xff) * shadeI) >>> 8;
      const b = (((c >>> 16) & 0xff) * shadeI) >>> 8;
      buf32[i] = (255 << 24) | (b << 16) | (g << 8) | r;
      i += W;
    }
  }
  ```
  Hoist `fogR / fogG / fogB / fogDenom` out of the `for x` loop (they're
  loop-invariant); the existing `render()` already does this at lines
  1374-1378, so the names are reusable.

- **Stone, floor, ceiling shared-helper:** the noise-based textures
  share a value-noise upsampler. PR #17 calls it `addOctave(target,
  scale, strength, rand)` and adds successive octaves into the same
  `Float32Array(TEX_SIZE * TEX_SIZE)`, then maps the field to RGBA at
  the end. Reuse this pattern — three octaves for stone, two for
  ceiling, none for the brick/floor grid textures.

- **Common pitfalls:**
  - **Forgetting the `castColumn` return-shape change.** `drawMinimap`
    and `castRay` ignore the new fields, but `render()` reads
    `hit.rayDirX` / `hit.rayDirY` — if you don't add them, walls render
    with `undefined` direction and `wallX` becomes `NaN`. Easy to spot
    (the canvas shows a single repeating column), but easier to just
    add them up front.
  - **Texture seams at corners.** The mirror rule for `texX` (AC #6
    / Design Notes) is the standard fix. If your bricks visibly
    flip-flop at every wall corner, the mirror condition is wrong.
  - **Sky/ground gradient still drawing.** If you forget to delete
    `SKY_ROW` / `GROUND_ROW` and their fill loops, the per-row cast
    overwrites them every frame anyway, so it'll *look* right but
    waste several hundred microseconds per frame and leak a confusing
    "why is this dead code still here" question into the next reader.
    Delete them.
  - **Fog formula drift.** The wall fog `t` uses `d` (perpWallDist);
    the floor/ceiling fog `t` uses `rowDist`. Don't mix them. Both
    map through the same `(t - FOG_NEAR) / (FOG_FAR - FOG_NEAR)`
    clamp, but the input distance is per-row for floor/ceiling and
    per-column for walls.
  - **Vignette pass running over wrong-sized buffer.** It runs over
    all `W * H` pixels regardless of where they came from — which is
    correct now (textured floor/ceiling included). Don't gate it on
    `if (lightingEnabled)` differently than today; the existing
    branch at line 1427 is right.
  - **`Math.random()` slipping into a generator.** Forbidden by the
    determinism contract. If you hit `Math.random` while typing,
    swap to the `rand()` LCG closure instead. The byte-identical
    first-frame requirement is the regression check.
  - **Per-pixel float in the inner loop.** Measure FPS — at 480×270
    the floor cast is `H/2 * W = 64,800` extra pixel ops per frame,
    plus the wall sample, plus sprites. Stay in `Uint32Array` /
    integer fixed-point land. The sketches above are integer-only;
    don't introduce `r * shade | 0` (float multiply) where you can
    use `(r * shadeI) >>> 8` (integer multiply).
  - **`zBuffer[x]` not set.** The wall pass still writes `zBuffer[x] =
    d` per column, and `drawSprites` reads it. If you accidentally
    delete that line during the wall-loop rewrite, sprites stop
    occluding behind walls. The sketch in Design Notes preserves it.
  - **Side-darken applied twice.** If you keep the existing
    `sideMul` AND import another `* 0.6` from the texture sample,
    side walls go nearly black. Apply side-darken exactly once,
    inside the inner loop, via the precomputed `sideMul`/`sideI`.
  - **Brick / stone hue flipped.** Brick = wallType 1 (red/orange),
    stone = wallType 2 (blue/grey). The current `MAP` uses both.
    `WALL_TEX[1] = TEXTURES.brick`, `WALL_TEX[2] = TEXTURES.stone`,
    not the reverse. Quick visual: stand in a corridor and verify
    the red walls match the existing red walls' positions.
